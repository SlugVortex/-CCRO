# Branding Prompts

## Logo prompt

```text
Create a professional logo for "Caribbean Climate Resilience Orchestrator" with the acronym CCRO.
Style: clean modern enterprise software identity.
Include a compact symbol and the text lockup "CCRO" with smaller subtitle "Climate Orchestrator".
Color palette: deep navy, azure blue, seafoam teal, with a subtle warm storm-signal coral accent.
Mood: crisp, confident, Microsoft-adjacent but not copying Microsoft branding.
Avoid: generic AI swirls, purple gradients, cartoon weather icons, palm trees, hurricane clipart, fake UI, watermark.
```

## GitHub banner prompt

```text
Create a wide GitHub repository banner for "Caribbean Climate Resilience Orchestrator".
The banner should feel like a polished enterprise-tech climate product.
Left side: strong title and subtitle.
Right side: stylized climate risk operations dashboard, regional map, agent flow cards, and layered data panels.
Palette: midnight navy, azure blue, seafoam teal, warm coral accents, and soft sand highlights.
Mood: strategic, modern, premium, professional.
Text: "Caribbean Climate Resilience Orchestrator" and "Multi-agent climate planning for resilient islands".
Avoid: fake corporate logos, generic AI faces, purple gradients, cartoon tropical art, watermark.
```
